5. 一次調査における用語・Event IDの定義

用語・Event ID 一般的な技術的意味 今回の調査における注目ポイントと重要度
Event ID 7045
(サービス作成)		 PCに新しいシステムプログラム（サービス）が追加・インストールされたことを記録します。 マルウェアや管理外ツール（ScreenConnect）が自動起動サービスとして登録された手口を検出するために重要です。
Event ID 7040
(スタートアップ変更)		 既存のサービスの起動設定（自動、手動、無効等）が変更されたことを記録します。 Windows Updateなどの際に、各種モジュールの起動タイプが変更されるログとして頻発します。
Event ID 4624
(サインイン成功)		 ユーザーまたはシステムがPCへのサインイン（ログイン）に成功した記録です。 外部のIPアドレスから、不審なログオンタイプ（リモートデスクトップを表すType 10等）でのサインインがないかを追跡します。
Event ID 4625
(サインイン失敗)		 パスワードの間違い等により、PCへのサインインに失敗した記録です。 短時間にこのログが大量発生している場合、総当たり攻撃（ブルートフォース）の疑いがあります。

6. 一次調査における制限事項および詳細解析依頼

  • ログ改竄およびポリシー未設定の懸念: hori PC のセキュリティログは合計480件しか記録されていません（他のPCは数千〜数万件）。外部からのリモートアクセスログオン（Type 3/10）が検知されなかったのは、攻撃者によってログが消去されたか、あるいは元々監査ポリシーが適切に設定されておらず、ログオン成功が記録されない設定になっていた可能性があります。業者の詳細解析によるログ復元、レジストリ内のセッション接続情報の調査、あるいはイベントログ消去プロセス（Event ID 1102）の痕跡有無の確認を依頼します。
  • メモリ上のみで動作するマルウェアの検知: イベントログはレジストリやファイルシステム、サービスの変更を伴うイベントは記録しますが、ファイルを作成せずメモリ上でのみ動的に実行される攻撃コードは検知できない場合があります。そのため、端末のメモリダンプ解析や、ディスク上の削除ファイルの復元、ネットワーク通信パケットログの相関解析を含めた総合的なフォレンジック調査を依頼します。
